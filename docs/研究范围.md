# 毕业设计研究范围（与整理版开题报告同步）

依据：[开题报告_整理版.md](开题报告_整理版.md)。本轮于 2026-11-12 同步研究边界；正式题目为“基于检索增强与证据筛选的网络安全问答系统设计与实现”。

## 1. 研究问题

1. CWE 知识段经过 DPR 召回与 Reader 评分后，能否找到回答安全知识问题所需的依据？
2. 在同一候选池下，MMR 相较 Reader Top-5 能否降低重复，同时保留有效知识？
3. 使用同一组 MMR 证据时，普通模式与增强模式在事实正确性、完整性、来源支持和运行开销上有何差异？

本课题定位为已有方法的安全领域适配、系统集成与受控验证，不预设筛选或生成必然提升效果。

## 2. 最低交付范围

| 环节 | 交付要求 |
| --- | --- |
| 知识库 | CWE 英文原文；字段分段、来源追溯、版本与哈希记录 |
| 更新 | 手动触发和定期检查；新增、修改、状态变化识别；知识段与索引同步；检查后切换并可回退 |
| 召回 | DPR 问题／段落双编码器，初始候选数 N=20 |
| 阅读 | DPR Reader 输出段落相关性及答案起止位置 |
| 筛选 | MMR 默认最多 5 段，候选不足返回实际数量，空候选或证据不足有明确提示 |
| 回答 | 普通模式抽取或返回原文；增强模式基于同组证据组织带编号的回答 |
| 界面与记录 | 问题、模式切换、答案、证据展开、来源 URL、条目 ID、字段、快照版本及运行记录 |
| 数据集 | 至少 120 道人工核验题，按来源条目划分开发集 80 题、冻结测试集 40 题 |
| 实验 | Reader Top-5 对比 MMR；相同 MMR 证据下普通模式对比增强模式；失败案例分析 |

## 3. 算法与工程约束

- Reader 相关性经统一尺度处理，作为 MMR 相关性项；冗余项为候选段落向量与已选段落向量的最大余弦相似度，已选集合为空时为 0。
- MMR 按 `λ × 相关性 − (1 − λ) × 冗余` 逐轮选择，至多 5 段；λ 与分数处理规则在开发阶段确定并冻结。
- 普通模式复用候选阅读阶段的答案位置和评分，只在最终选定知识段中取答案。单跨度无法充分回答时展示相关原文。
- 增强模式使用同一证据集合与顺序，记录模型、权重版本、精度、提示词与解码参数。Llama 仅为候选示例，尚未确定具体模型。
- 输入长度检查保证所选证据可装入模型上下文；长度不作为新增筛选目标。
- 优先使用与现有英文 DPR 模型匹配的英文问题与原文；中文查询须单独验证。
- 日常查询使用最近一次成功更新的知识库；正式实验固定知识库、处理规则、模型及配置。

## 4. 评价与复现

检索层报告 Recall@N；筛选层报告 Evidence Recall@5、有效知识段比例、平均段间相似度及实际段数；回答层人工核验关键事实正确性、完整性、来源支持和无依据陈述。有标准答案跨度的子集补充 EM/F1，综合题以事实和证据核验为主。

分别测量召回、Reader、筛选与回答耗时，比较端到端延迟及资源使用。失败原因区分数据缺失、召回遗漏、Reader 评分偏差、MMR 漏选、抽取失败和生成误用。引用编号有效性检查不能代替事实支持核验。详情见[实验规范](../experiments/README.md)。

## 5. 可选扩展与早期探索

NVD 等来源、中文查询支持应在核心链路完成后另行验证并记录范围，不作为最低交付要求。无需为了本轮课题新增大模型训练、量子硬件或复杂领域评分。

已有 DSES 实现、配置、示例与测试原位保留，属于早期探索；现有安全 ID 功能仅为标识解析，尚不是完整路由检索。DSES、QORE/QUBO、字段覆盖和长度成本优化不属于本轮主方法，也不要求四方法对照或 DSES 消融。

## 6. 个人工作与复用边界

拟复用前期 DPR 编码、Reader 相关性评分与 MMR 基线接口，接入前核对模型输入、分数含义、段落顺序和返回格式。个人计划工作包括安全数据解析与更新、双模式集成、界面与证据展示、人工核验集及实验评价。来源与实际完成证据记录在[贡献说明](../CONTRIBUTIONS.md)。
