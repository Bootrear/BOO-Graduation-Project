# 人工核验与数据集划分规范

依据[开题报告](../../docs/开题报告_整理版.md)，至少构建 120 道人工核验题，开发集 80 题、冻结测试集 40 题。当前目录尚无正式题目或完成核验的数据集。

## 题目范围与字段

优先使用与英文 DPR 模型匹配的 CWE 英文原文和英文问题，覆盖定义、后果、检测与缓解。中文题需另行验证并单独记录结果。每题建议以 JSONL 保存：

| 字段 | 内容 |
| --- | --- |
| `question_id`、`question`、`language` | 题号、问题及语言 |
| `intent`、`record_ids` | 题型与所有支持来源条目 ID |
| `answer_type` | `single_span` 或 `multi_passage` |
| `answer_variants`、`gold_facts` | 可接受答案与需要核对的关键事实 |
| `required_evidence_ids`、`optional_evidence_ids` | 必要和补充知识段；事实与支持段的对应关系须可追溯 |
| `source_snapshot` | 固定知识库版本与清单引用 |
| `split` | `dev` 或 `test` |
| `annotator`、`reviewer`、`status` | 实际标注、核验人员及状态，不虚构独立复核 |

## 划分与冻结

1. 人工检查问题可由指定快照回答，核对答案、必要事实与来源原文。
2. **按来源条目分组划分**，同一 CWE 条目不得同时出现在开发集和测试集；多条目题的全部支持条目应在同一组，避免跨集泄漏。
3. 保存题目 ID、条目 ID、划分清单及文件哈希。先满足 80／40 题及题型覆盖要求，再冻结测试集。
4. MMR λ、分数尺度、模型配置、证据不足规则及提示词只在开发集确定；冻结测试集不用于调参。
5. 单跨度题可补充 EM/F1；综合题以事实、完整性及来源支持核验为主。证据编号存在不能替代支持关系检查。
