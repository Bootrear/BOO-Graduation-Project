# 统一问答流程（待实现）

本目录目前仅定义职责，不包含可运行实现。

计划统一串联：问题 → DPR 召回 → Reader 评分与答案位置 → MMR 筛选 → 普通／增强回答。界面与实验调用同一处理链路；Reader Top-5 是实验中的筛选替代项。

一次运行固定知识库版本，记录问题、候选 ID 及分数、Reader 答案位置、筛选顺序、最终证据、模式、回答和各阶段耗时。模式对比应复用选定证据，不能重新召回产生不同证据。空候选、证据不足和原文回退的判定规则需在开发集确定并记录。

日常知识库更新由数据与索引模块完成；只有一致性检查通过的快照才可启用。正式实验指定冻结快照，不能随当前在线版本变化。
