# 双模式回答（待实现）

本目录目前仅定义职责，不包含可运行实现。两种模式必须使用同一组 MMR 证据及顺序，默认至多 5 段。

| 模式 | 计划行为 |
| --- | --- |
| 普通模式 | 在选定证据内复用 Reader 答案位置及评分，返回原文答案和来源；单跨度不足以回答时展示相关原文 |
| 增强模式 | 将问题和带编号的同组证据输入所选 LLM，组织自然语言回答并标记依据；证据不足时说明无法确认 |

保留条目 ID、字段、原文、URL 和快照供界面展开。检查答案引用编号是否属于输入证据，人工核验引用是否支持事实。模型权重、精度、提示词、解码参数及上下文长度检查在开发阶段确定并冻结。
